# Changelog

## 0.1.0

First release.

- `slotguard check`, `snapshot` and `diff` commands.
- GitHub Action with a sticky PR comment, job summary, annotations and `fail-on`.
- Foundry and Hardhat 2/3 support, including base checkouts with submodules, `node_modules` and Soldeer dependencies.
- Storage layout rules for inserted, moved, removed, retyped, replaced and renamed variables, storage gaps, packed variables and nested structs.
- ABI rules for removed functions, events, errors, `receive` and `fallback`, changed outputs, mutability and indexed parameters.
